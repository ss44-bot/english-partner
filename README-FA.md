# 📱 English Partner — اپ دستیار زبان من

اپی که روی **آیفون** نصب می‌شود (مثل یک اپ واقعی) و روی **کامپیوتر** هم همان است.
متصل به هوش مصنوعی، دیکشنری، ترجمه، تلفظ، ضبط صدا، مرور فاصله‌دار و آرشیو درس‌ها.

---

# 🔗 چطور بازش کنم؟

## لینک عمومی GitHub Pages
**https://ss44-bot.github.io/english-partner/**

> یک‌بار (صاحب ریپو): [Settings → Pages](https://github.com/ss44-bot/english-partner/settings/pages) → Source = **GitHub Actions** → بعد workflow سبز می‌شود.

## روی کامپیوتر (همین حالا)
پیش‌نمایش زنده‌ای که در چت باز شده (برچسب: **English Partner app**) — یا آدرس `http://localhost:8000` وقتی خودت اجرا کنی.

ریپو: https://github.com/ss44-bot/english-partner  
PR: https://github.com/ss44-bot/english-partner/pull/1

## روی آیفون (نصب مثل اپ) 📲
1. آدرس اپ را در **سافاری** باز کن (نه کروم).
2. دکمهٔ **Share** (مربع با فلش رو به بالا) را بزن.
3. پایین لیست → **Add to Home Screen** → **Add**.
4. حالا یک آیکون روی صفحهٔ گوشی‌ات داری که **تمام‌صفحه** باز می‌شود (بدون نوار سافاری) — دقیقاً مثل اپ.

> ⚠️ برای میکروفون و کار کردن همه‌چیز، آدرس باید **https** باشد (آدرس پیش‌نمایش این‌طور است). اگر فایل را دانلود کنی و با `file://` باز کنی، ضبط صدا کار نمی‌کند.

# 🔑 اتصال به هوش مصنوعی (تنظیمات → کلید API)

بدون کلید API، این‌ها کار می‌کنند: **دیکشنری + ترجمهٔ فارسی + تلفظ + کارت‌ها + ضبط صدا + مرور فاصله‌دار**.
با کلید API، این‌ها هم اضافه می‌شوند: **تحلیل عکس صفحهٔ کتاب، چت با مربی، همنشینی‌ها، معادل نیتیو، اشتباهات رایج**.

| سرویس | سایت گرفتن کلید | مدل پیشنهادی | هزینه |
|---|---|---|---|
| **Google Gemini** (ساده‌ترین) | aistudio.google.com/app/apikey | `gemini-2.0-flash` | رایگان با محدودیت روزانه |
| **OpenAI** | platform.openai.com/api-keys | `gpt-4o-mini` | ارزان، پرداختی |
| **OpenRouter** (دسترسی به همهٔ مدل‌ها) | openrouter.ai/keys | `openai/gpt-4o-mini` یا `google/gemini-flash-1.5` | پرداختی/بعضی رایگان |
| **Anthropic Claude** | console.anthropic.com/settings/keys | `claude-3-5-sonnet-latest` | پرداختی |
| **Groq** (سریع و رایگان) | console.groq.com/keys | `llama-3.3-70b-versatile` | رایگان |

**روش کار:** Settings → Provider → کلید را بچسبان → دکمهٔ **🔌 تست اتصال**.
🔒 کلید فقط داخل حافظهٔ همان مرورگر می‌ماند و به هیچ‌جای دیگری نمی‌رود.

# 🧩 اپ چه کاری می‌کند؟

| تب | کار |
|---|---|
| 🏠 **خانه** | زنجیرهٔ روزها، کارت‌های سررسیده، قدم بعدی، **📓 دفتر چهار جمله** |
| 💬 **جلسه** | چت با مربی + ۹ دکمهٔ مرحله (زمینه → آموزش → تکرار → تولید هدایت‌شده → نقش‌آفرینی → تصحیح → تست → لایهٔ عمیق → آزاد) + **🎬 صحنه (بصری)** + **📷 عکس صحنه** |
| 📸 **صفحه** | عکس صفحهٔ کتاب (چند کتاب با هم) → درس کامل + ارجاع متقابل + خوشه‌ای + **پیست متن صفحه / فایل متنی** |
| 🗣️ **گفتن** | صدای مدل / آهسته / ضبط / مقایسهٔ A-B + **🔁 حالت سایه (Shadowing) با وقفه و تعداد دور** + پروتکل ۷ مرحله‌ای + آرشیو ضبط‌ها |
| 🎬 **ویدیو** | **روش ۴ پاس** با چک‌لیست و تایمر + عبارت‌های جست‌وجوی یوتیوب هر ماژول + کانال‌ها + **🧺 برداشت چانک** (به «گفتن» یا کارت‌ها) |
| 📖 **واژه** | دیکشنری + IPA + تلفظ واقعی + ترجمهٔ فارسی + همنشینی/مثال/معادل نیتیو با AI |
| 🃏 **کارت‌ها** | ساخت کارت، مرور فاصله‌دار ۱/۳/۷/۱۴/۳۰، خروجی Anki (CSV) |
| ⋯ **بیشتر** | 📊 آمار، **🟥 دفتر اشتباهات**، 🗓 برنامهٔ هفتگی، ✅ **چک‌لیست خواسته‌ها**، 🗺 **نقشهٔ ۱۵۰ موقعیت**، 📋 پرامت‌ها، ⚙️ تنظیمات |
| ⚙️ **تنظیمات** | سرویس‌دهنده، کلید، لهجه، سرعت پخش، صدای مرورگر، پشتیبان‌گیری |

**هوشمندهای داخل اپ:**
- 🔊 روی هر پاسخ مربی، **فقط خطوط انگلیسی** خوانده می‌شود (فارسی رد می‌شود) — برای شدووینگ.
- 🗣️ دکمهٔ «تمرین در گفتن»: خطوط انگلیسی یک درس را خودکار به لیست تمرین گفتن اضافه می‌کند.
- 🃏 دکمهٔ «ساخت کارت‌ها»: از متن درس، چانک‌ها را استخراج و به‌صورت کارت مرور ذخیره می‌کند.
- 🟥 دکمهٔ «ثبت اشتباه» روی هر پاسخ مربی: جملهٔ غلط و نسخهٔ درست را در دفتر اشتباهات ذخیره می‌کند.
- 💾 دانلود درس (Markdown) + پشتیبان کل اپ (JSON).

# 📐 قالب اجباری خروجی آموزش (چک‌لیست ۱۱ بلوکی)

این قالب حالا **داخل خود اپ** (پیام سیستمی مربی) نوشته شده، پس در هر جواب اجباری است — نه فقط وقتی یادت بیاید بخواهی:

| # | بلوک | جزئیات اجباری |
|---|---|---|
| ۱ | 📸 محتوا و زمینه | کتاب/واحد + کد موقعیت + صحنهٔ حسی + داستان فارسی + سؤال‌های توصیف |
| ۲ | 📘 واکاوی واژگانی | **معنی‌های چندگانه با موقعیت جدا** · Word Family (اسم/فعل/صفت/قید/متضاد) · کالوکیشن سطح‌بندی‌شده · اشتباه رایج فارسی‌زبان |
| ۳ | 🔧 **افعال کنشی/حرکتی/لمسی** | ۵ ستون: تفکیک هم‌خانواده‌ها (turn/twist/rotate/spin — tear/rip/shred — open/uncap/unscrew/pop open) · مکانیسم فیزیکی با ژست · مفعول‌های همراه · محیط کاربرد · سطح رسمیت |
| ۴ | 📌 موقعیت‌های واقعی | حداقل **۵ روش** از رسمی→نیتیو + لحن در محیط‌های مختلف + راهبرد پاسخ + بک‌چنل |
| ۵ | ⚡ گرامر گفتاری | جدول ❌/✅ تداخل فارسی + **کاهش‌ها** (gonna/didja/lemme/kinda) + استرس و آهنگ جمله |
| ۶ | 💬 عبارات کلیدی | حداقل ۵ آیتم سطح‌بندی‌شده (افعال عبارتی، اصطلاح، کالوکیشن) |
| ۷ | 🎬 دیالوگ و نقش‌آفرینی | دیالوگ دوزبانه ۶–۱۰ نوبتی + **نوبت‌های من** + سه سطح پاسخ (🟩🟦🟪) + باکس نجات |
| ۸ | 🔁 دریل | خطوط تکرار با راهنمای تلفظ + دریل پرسش-پاسخ + پادکست کوتاه |
| ۹ | 🧩 تولید هدایت‌شده | ۶–۸ جای‌خالی با زندگی واقعی من + ۵ جملهٔ فارسی→انگلیسی (جواب‌ها پنهان) |
| ۱۰ | 🧠 حافظه | تصویر ذهنی هر چانک + کد موقعیت + تاریخ مرور ۱/۳/۷ |

# 🖥 اجرای نسخهٔ محلی (اگر خواستی همیشه داشته باشی)

```bash
# در پوشهٔ app
python3 -m http.server 8000
# بعد در مرورگر: http://localhost:8000
```

**برای دسترسی از گوشی در همان وای‌فای:** آدرس `http://IP-کامپیوتر:8000` را در سافاری بزن.
(ولی برای میکروفون و نصب PWA، آدرس https لازم است — ساده‌ترین راه: اپ را روی **Netlify Drop** یا **GitHub Pages** بگذاری؛ فقط پوشهٔ `app` را بکش و رها کن.)

# 📂 فایل‌های اپ

```
app/
├── index.html            ← صفحهٔ اصلی
├── styles.css            ← ظاهر (موبایل‌اول، RTL)
├── manifest.webmanifest  ← معرفی اپ برای نصب روی گوشی
├── sw.js                 ← آفلاین‌سازی پوسته
├── icon.svg / icon-180.png / icon-512.png
└── js/
    ├── data.js     ← چانک‌ها، مرحله‌ها، سرویس‌دهنده‌ها، خوشه‌های کتابی
    ├── prompts.js  ← پیام سیستمی مربی + همهٔ پرامت‌ها
    ├── ai.js       ← اتصال به OpenAI / Claude / Gemini
    └── app.js      ← منطق: چت، TTS، ضبط، دیکشنری، کارت‌ها، تنظیمات
```

**جای ذخیرهٔ اطلاعات:** همه‌چیز در مرورگر خودت (localStorage برای کارت‌ها/چت/تنظیمات، IndexedDB برای فایل‌های صوتی). هیچ سروری اطلاعات تو را ندارد.
