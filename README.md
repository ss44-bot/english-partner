# English Partner

PWA language coach (RTL / Persian UI) — dictionary, spaced repetition, shadowing, AI lesson chat.

## Live demo

- **GitHub Pages:** https://ss44-bot.github.io/english-partner/
- Local: `python3 -m http.server 8000` → http://localhost:8000

## Setup

1. Open the app.
2. Settings → pick a provider (Gemini / OpenAI / Groq / …) → paste API key → Test.
3. On iPhone: Safari → Share → **Add to Home Screen**.

API key stays in your browser `localStorage` only.

See [README-FA.md](./README-FA.md) for the full Persian guide.
